# Pradipta Haldar — Personal Portfolio

> A personal portfolio website showcasing my projects, technical skills, education, and experience as a Computer Science and Business Systems student.

🌐 **Live Portfolio:** https://nillportfolio.netlify.app/

---

## 📌 About

This repository contains the source code for my personal portfolio website.

The portfolio is designed to provide a simple and professional way to explore my:

- 👨‍💻 Projects
- 🛠️ Technical skills
- 🎓 Education
- 📬 Contact information
- 🚀 Development journey

The website uses a separate frontend and backend architecture, with the contact form connected to a production REST API.

---

## ✨ Features

- Responsive personal portfolio website
- Hero / introduction section
- About section
- Technical skills section
- Projects showcase
- Education section
- Contact form
- REST API for contact form submissions
- Email delivery through Resend
- Scroll-based animations
- Production deployment
